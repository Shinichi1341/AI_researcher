# レビューメモの書き方

このディレクトリに Markdown ファイルを置くと、パイプラインが自動で
記事に仕上げます。

## フォーマット

```markdown
---
keyword: クラフトジン 〇〇
category: お酒
rating: 4.0
---
ここに自分のレビューを書く。箇条書きでも文章でもOK。
```

## フィールド説明

| フィールド | 必須 | 説明 |
|-----------|------|------|
| keyword   | ○   | 商品名やキーワード（SEO・商品検索に使用） |
| category  | △   | カテゴリ（デフォルト: "お酒"） |
| rating    | △   | 自分の評価 1.0〜5.0 |

## 例

ファイル名は何でもOK（例: `craft-gin-roku.md`）。
パイプライン処理済みのファイルは `data/processed_reviews.json` で追跡されます。
